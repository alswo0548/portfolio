### 01 · OCTV

CCTV로 탐지한 재난 사건의 위험도와 대응 우선순위를 판단하고, 대응 기관·접근 경로 결정을 돕는 관제 플랫폼입니다.
DB 설계, 사건 저장·조회 API, 기관별 조회 권한, AI 판단 작업 큐, 외부 API·MCP 연동을 구현했고 판단·추천 기능을 개발하고 있습니다.
