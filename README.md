### 01 · OCTV

CCTV로 탐지한 재난 사건의 위험도와 대응 우선순위를 판단하고, 대응 기관·접근 경로 결정을 돕는 관제 플랫폼입니다.
팀장으로 외부 API·MCP 연동, LangGraph 사건 분석, 위험도·기관·경로 추천, 기관 전달·FCM 알림, CCTV 적응학습과 배포 통합을 맡았습니다. **실제 웹 시연 영상 4개**가 있습니다.

### 03 · Climbing Web

클라이밍 종목 소개, 지도 기반 클라이밍장 찾기와 성향 설문 추천, 선수 기록 차트를 담은 5페이지 웹사이트입니다.
화면 설계부터 HTML · CSS · JavaScript 구현까지 혼자 진행했고, Kakao 지도 · OpenWeather API를 연동했습니다. **실제 시연 영상 3개**가 있습니다.
